# Security policy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/w21180239/human-typing/security/advisories/new), not in a public issue.

Relevant reports include text that makes a plan run page JavaScript other than the clipboard write, press Enter or click when it should not, break out of the quoted Browser MCP `eval` command, leave the user's clipboard overwritten, or make `clip save` / `clip restore` read or write files other than its temp file.

Only the latest release is supported. Expect a first reply within a week.
